### Womit ich gearbeitet habe

- **Netzwerk:** IP-Planung und Subnetting, VLANs, statisches Routing, NAT, DHCP, DNS, Firewall (OPNsense), VPN (WireGuard/NetBird), Wireshark
- **Server und Virtualisierung:** Proxmox VE, KVM und LXC, Windows Server 2025, Active Directory, Gruppenrichtlinien, Debian und Ubuntu
- **Datenbanken:** SQL, PostgreSQL, MariaDB, ER-Modell und Normalisierung, DBeaver
- **Betrieb:** Ansible, Docker, Zabbix, Prometheus und Grafana, Backup und Wiederherstellung
